# דף הנחיתה — יסודות המודיעין

עמוד הבית המלא: מסך הפתיחה עם החץ, מסך שלוש כרטיסיות הפרקים, ה-Header וה-Footer.
שתי צורות שימוש — לבחור אחת.

## 1. קובץ אחד עצמאי

**`landing.html`** — 861KB, פותחים בלחיצה כפולה. אין התקנה, אין build, אין תלות.
כל ה-CSS בתוך `<style>`, כל התמונות מוטמעות כ-base64, והגלילה מהחץ אל הפרקים
בסקריפט קצר בסוף הקובץ.

מתאים כשרוצים להראות את הדף, לשלוח אותו, או להעלות אותו כמו שהוא לאחסון סטטי.

## 2. קומפוננטת React

```
LandingPage.jsx    כל ארבעת החלקים בקובץ אחד
landing.css        כל העיצוב
assets/            חמש תמונות
```

להעתיק את שלושתם לפרויקט, ואז:

```jsx
import LandingPage from './landing-export/LandingPage'

export default function App() {
  return <LandingPage />
}
```

דורש React 17 ומעלה (JSX transform אוטומטי). בפרויקט ישן יותר — להוסיף
`import React from 'react'` בראש הקובץ.

**אין תלות ב-react-router.** הקישורים הם `<a href>` רגילים. כדי לחבר אותם
לניתוב של הפרויקט החדש, יש להחליף ל-`<Link to>` בשלושה מקומות:
המיתוג ב-Header ושלושת הכרטיסים.

## מה צריך לעדכן בפרויקט החדש

**הקישורים.** בראש `LandingPage.jsx` יש אובייקט `content` ובו כל הטקסטים
והנתיבים. שדות `to` של הכרטיסים מצביעים על `/chapter/...` של האתר הנוכחי.

**כיוון העמוד.** `landing.css` מגדיר `direction: rtl` על ה-body. אם ה-HTML
של הפרויקט החדש כבר מגדיר `dir="rtl"` — מה טוב, זה לא מתנגש.

**גובה ה-Header.** המשתנה `--header-h: 88px` הוא מספר שכל שאר המסכים
נמדדים לפיו: גובה מסך הפתיחה, עצירת הגלילה, וגובה רצועת הפרקים.
שינוי גובה ה-Header מחייב לעדכן את המשתנה ולא את הכללים עצמם.

**גובה ה-Footer.** באותו אופן, `--footer-h: 132px` בכלל של `#topics`.
אם ה-Footer בפרויקט החדש גבוה או נמוך יותר, יש לעדכן את המספר — אחרת
מסך הפרקים לא ישלים בדיוק את גובה המסך.

## הערות

**הפונט.** מערכת הטיפוגרפיה מבקשת Assistant ואז Heebo, ונופלת ל-Segoe UI
או Arial Hebrew. האתר הנוכחי אינו טוען אותם מ-Google Fonts, ולכן הוא מוצג
בפועל בפונט המערכת. אם רוצים את Assistant בוודאות, להוסיף ל-head:

```html
<link href="https://fonts.googleapis.com/css2?family=Assistant:wght@400;600;700&display=swap" rel="stylesheet" />
```

**התמונות.** דחוסות מהמקור כדי שהקובץ העצמאי יישאר שפוי: מסך הפתיחה
1234×717 ב-JPEG, תצלום פרק 1 הוקטן ל-1200 פיקסלים רוחב, והלוגו נשאר PNG
בשל השקיפות. סך הכול 452KB במקום 5MB. המקורות המלאים נמצאים ב-
`src/assets/images/` של הפרויקט המקורי.

**ה-CSS.** `landing.css` כולל את קובץ הבסיס הגלובלי של האתר במלואו, ובו
גם כללים שאינם בשימוש בדף הנחיתה (מחלקות עזר של עמודי הפרקים). הם נשארו
כדי לא לשבור כלום בטעות, וניתן לנקות אותם בהמשך.
