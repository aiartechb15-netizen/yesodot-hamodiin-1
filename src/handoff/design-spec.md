# מפרט המבנה העיצובי — "פרק 1"

מסמך זה מתאר **שכבה חזותית בלבד**: פלטה, טיפוגרפיה, ריווח, שלד עמוד ואנטומיית רכיבים.
אין בו תוכן, אין בו טקסטים ואין בו לוגיקה. הוא נועד להיות מוחל על אתר קיים שכבר יש בו כל התוכן.

הקובץ הנלווה `design-system.css` הוא המימוש המלא של המסמך הזה — קובץ אחד, עצמאי, מוכן להדבקה.
כל המחלקות בו מקודמות ב-`lx-` כדי שלא יתנגשו ב-CSS קיים.

---

## 1. חמשת החוקים שאין לשבור

1. **שלושה צבעים בלבד** — נייבי, טורקיז, זהב. אין צבע רביעי. אין ירוק: הצלחה = טורקיז.
   הבחנה נוספת נעשית בשקיפות, במשקל גופן או בקו מפריד — לא בגוון חדש.
2. **הגבול הוא בז׳** (`#ded9cf`), לא אפור. **הצללים בנייבי שקוף**, לא בשחור.
   זה מה שיוצר את תחושת ה"נייר" במקום תחושת "אפליקציה".
3. **RTL בתכונות לוגיות בלבד** — `margin-inline-start`, `inset-inline-start`, `border-inline-start`,
   `text-align: start`. אף פעם לא `left`/`right`.
4. **נגישות AA לפחות** — כל אינטראקציה עובדת בלחיצה ובמקלדת, אין תוכן חובה בהובר,
   פוקוס אחיד `3px solid var(--lx-teal)`, יעד מגע 44px מינימום.
5. **חשיפה מדורגת** — תוכן נפתח לפי בחירת הלומד (לשוניות, אקורדיון, כרטיסי חשיפה),
   לא כטקסט רציף אינסופי.

### שתי נקודות ניגודיות שכבר נפתרו — אל תשנו אותן חזרה
| טוקן | ערך | למה |
|---|---|---|
| `--lx-gold-ink` | `#7c6426` | הזהב עצמו נכשל כטקסט קטן. הגוון הכהה עובר AA גם על קרם (4.99). |
| `--lx-teal-ink` | `#0f6f71` | `--lx-teal` הוא 3.3 על נייר ולכן נכשל כטקסט קטן. הגוון הכהה מגיע ל-5.6. |

`--lx-teal` עצמו נשאר לאייקונים, גבולות, מילויים וטבעת הפוקוס.
**על רקע נייבי חוזרים ל-`--lx-teal-light`** — שם `--lx-teal-ink` כהה מדי.

## 3. טיפוגרפיה

- **כותרות:** Rubik. **גוף וממשק:** Assistant. שני גופנים, לא יותר.
- כל הגדלים `clamp()` — רספונסיביים בלי media queries.

| | גודל | משקל |
|---|---|---|
| `h1` | `clamp(1.95rem, 4.6vw, 3rem)` | 800, `letter-spacing: -0.01em` |
| `h2` | `clamp(1.55rem, 3.2vw, 2.15rem)` | 700 |
| `h3` | `clamp(1.2rem, 2.2vw, 1.4rem)` | 700 |
| `h4` | `1.0625rem` | 700, **בגופן הגוף** ולא בכותרות |
| lead | `clamp(1.075rem, 1.9vw, 1.25rem)` | רגיל, `line-height: 1.62` |
| גוף | `1.0625rem` | רגיל, `line-height: 1.72` |
| קטן / זעיר | `0.9375rem` / `0.8125rem` | |

**אורך שורה הוא הפרמטר החשוב ביותר לקריאוּת:** `p { max-width: 68ch }`, lead `62ch`.
אל תבטלו את זה כדי "למלא את הרוחב".
גובה השורה מהודק במכוון — לעברית יש x-height גבוה.

## 4. ריווח ומידות

בסיס 8px: `4 · 8 · 12 · 16 · 24 · 32 · 48 · 64 · 96`.

| | ערך |
|---|---|
| ריפוד אנכי של סקשן | `clamp(56px, 8vw, 104px)` |
| רוחב עטיפה | `1120px` (צר: `720px`) |
| רדיוס | `4 / 8 / 14 / 999px` |
| מוֹשן | `130ms` מהיר · `200ms` רגיל · `320ms` איטי · `cubic-bezier(0.2, 0.7, 0.3, 1)` |
| גובה header | `64px` · סרגל התקדמות `52px` |

`prefers-reduced-motion` מאפס את כל משכי האנימציה ל-`1ms` וכן את הגלילה החלקה.

## 5. שלד העמוד

זה סדר הקומפוננטות בעמוד פרק. **הסדר עצמו הוא חלק מהעיצוב** — הוא מה שהופך עמוד תוכן לחוויית פרק.

```
┌─ Header דביק (נייבי, גובה 64px)
│    סימן זהב + שם + תת-שם | ניווט בין הפרקים
│
├─ Hero (נייבי, שני טורים)
│    [מספר בריבוע זהב] פרק N · ⌁ · כ־N דקות
│    H1 גדול
│    תת-כותרת בזהב, משקל רגיל
│    ─── קו זהב 46px
│    פסקת lead
│    ─────────────────────
│    "בסיום הפרק תוכלו" + 4–6 תוצאות למידה
│    [כפתור לבן: מתחילים]                      ← בנייד התמונה עולה למעלה
│                                    [תמונת אווירה 4:3]
│
├─ סרגל התקדמות דביק (נייר שקוף + blur, יושב מתחת ל-header)
│    "תחנה 3 מתוך 7" | צ׳יפים לכל תחנה, הפעילה מודגשת | פס מילוי טורקיז
│
├─ סקשן: פתיחה                      [נייר]
│    kicker → H2 → קו זהב → lead → פסקאות → callout → וידאו
│
├─ סקשן: מפת העמוד                  [נייבי]   ← ניגוד ראשון
│    תמונה רחבה 21:9
│    3 כרטיסי "שער" — מסגרת זהב, פס זהב עבה בצד הפותח, hover מרים 3px
│
├─ סקשן: שער 1                      [נייר]
│    בלוקים: תווית טורקיז זעירה → H3 → פסקאות → grid כרטיסים → callout
│
├─ סקשן: שער 2                      [קרם]     ← ניגוד שני
├─ סקשן: שער 3                      [נייר]
│
├─ סקשן: תרגול מסכם                 [קרם]
│    בלוקי תרגול עם רווח 48px ביניהם
│
├─ סקשן: סיום                       [נייבי]   ← סגירה על אותו גוון של הפתיחה
│    רשימת השלמות עם סימוני V בזהב + כרטיס ניקוד עם פס זהב בצד
│
├─ ניווט לפרק הבא/הקודם
└─ Footer (נייבי): מותג | רשימת פרקים | קרדיטים | שורת תחתית
```

### מקצב הרקעים
`נייר → נייבי → נייר → קרם → נייר → קרם → נייבי`

הכלל: **אף פעם לא שני סקשנים סמוכים באותו גוון**, ונייבי שמור לשלוש נקודות בלבד —
פתיח, מפת העמוד, סיום. סקשן `cream` ו-`white` מקבלים `border-block: 1px solid var(--lx-border)`.

## 6. אנטומיית הרכיבים

### כותרת סקשן — התבנית הכי חוזרת באתר
תמיד ארבעה חלקים באותו סדר, בלי יוצא מן הכלל:

```html
<header class="lx-head">
  <span class="lx-kicker">פתיחה</span>          <!-- טורקיז, 0.8125rem, letter-spacing 0.14em -->
  <h2>כותרת הסקשן</h2>
  <hr class="lx-rule-gold">                      <!-- 46×3px זהב -->
  <p class="lx-lead">משפט תקציר אחד או שניים.</p>
</header>
```

### סקשן
```html
<section id="anchor-id" class="lx-section lx-section--paper">
  <div class="lx-wrap">…</div>
</section>
```
ה-`id` הוא העוגן שסרגל ההתקדמות קופץ אליו. גוונים: `--paper` · `--white` · `--cream` · `--navy`.

### כרטיס
לבן · גבול בז׳ · רדיוס 14px · צל עדין · ריפוד 24px. זה הכל.

### הערת צד (callout) — שלושה וריאנטים
| וריאנט | רקע | צבע התווית | שימוש |
|---|---|---|---|
| ברירת מחדל | לבן | זהב כהה | "לתשומת לבכם", הנחיה |
| `--teal` | טורקיז שקוף 12% | טורקיז כהה | "רעיון מרכזי", תובנה |
| `--example` | קרם | נייבי משני | "דוגמה מהשטח" |

תמיד עם תווית עילית זעירה במשקל 700 ו-`letter-spacing: 0.1em`.

### כרטיס "שער" — כרטיס הניווט של מפת העמוד
רקע `--lx-navy-secondary`, מסגרת זהב שקוף, **פס זהב 4px בצד הפותח** (`border-inline-start`),
תווית "שער N" בגלולה, כותרת לבנה, תיאור בטורקיז בהיר, ובתחתית — שורת "מעבר לשער ←"
מופרדת בקו, נדחפת לתחתית ב-`margin-block-start: auto`.
Hover: הרמה 3px + מסגרת זהב מלאה + צל עמוק.

### בלוק משנה
```html
<div class="lx-block">
  <span class="lx-block__kicker">יסוד ראשון</span>
  <h3 class="lx-block__title">כותרת הבלוק</h3>
  <p>…</p>
</div>
```
רווח `64px` בין בלוקים, `16px` בין ילדים בתוך בלוק.

### כפתורים
ראשי נייבי · משני שקוף עם גבול · על נייבי לבן · רפאים על נייבי.
מינימום 44px גובה, `active` יורד 1px.

### תבליטים
`list-style: none` + ריבוע זהב 7px מעוגל קלות ב-`::before`. אף פעם לא bullet של הדפדפן.

### טבלה
עטופה ב-`overflow-x: auto` עם גבול ורדיוס. שורת כותרת על רקע קרם בגופן הכותרות.
`text-align: start` — לוגי, לא `right`.

## 7. מקומות שמורים לנכסים

תמונה או וידאו שטרם הופקו לא נעלמים — מוצג מקום שמור עם מזהה, יחס גובה-רוחב,
כיתוב ותיאור של מה אמור להיות שם. כך המבנה נשאר שלם והנכס נכנס אחר כך בלי לשבור פריסה.
יחסים בשימוש: `4/3` בפתיח, `21/9` לתמונה רחבה, `16/9` לווידאו.
